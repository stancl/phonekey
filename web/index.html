phonekey

    Pair a passkey

    Run phonekeyd pair-code on the backend host and enter the code. Pairing creates a passkey for this site, derives an SSH key from it and registers the public key.

    Already paired on another device or browser?

    Key registered

    Add this key to GitHub twice, as an Authentication key and as a Signing key, and to the dev box's git/jj signing config.

        Grants
        
        
        Approve + rest of … keeps the key in this page's memory for a short time and signs
          further requests from the same command (one jj sign, jj git push or
          git rebase -S) without asking again. Which command a request belongs to comes from the dev box,
          so a compromised dev box could pass a request off as part of it.
